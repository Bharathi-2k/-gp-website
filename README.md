# GP Anikalan - Premium Jewellery Boutique

A luxury, fully responsive static website for GP Anikalan built with HTML5, CSS3, and Vanilla JavaScript.

## Technologies Used
- HTML5
- CSS3 (Custom Variables, Flexbox, Grid)
- Vanilla JavaScript (ES6+)

## Project Structure
- `index.html`: The main single-page application entry point.
- `css/style.css`: All styling, taking a mobile-first responsive approach, with a premium brand theme (Ivory, Champagne Gold, Charcoal).
- `js/script.js`: Provides interactivity, including scroll animations, dynamic product filtering, search, and centralized external links logic (`SHOP_CONFIG`).
- `assets/images/`: Contains all high-quality placeholder and product images.

## Setup Instructions
1. This is a fully static website. No database or server is required.
2. Open `index.html` in any modern web browser to view the application locally.
3. For local development with live reloading, you can use an extension like VS Code Live Server or run a simple python server (`python -m http.server`).

## Features
- Dynamic sticky header with mobile hamburger menu
- Comprehensive product filter and instant client-side search
- Modal popups for product details with integrated WhatsApp ordering
- Custom scroll reveal animations and smooth scrolling
- Fully responsive styling across mobile, tablet, and desktop viewports
